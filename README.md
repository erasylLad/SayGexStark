   # 🚀 Digital Buddy — ИИ-Наставник АО «НК «КазМунайГаз»

Инновационная система автоматизации адаптации (онбординга) и психологической поддержки новых сотрудников АО «НК «КазМунайГаз» на базе искусственного интеллекта, интегрированная с Битрикс24.

---

## 📌 Описание проекта
**Digital Buddy** — это не просто чат-бот, а комплексная экосистема, которая помогает новому сотруднику быстро влиться в рабочие процессы компании КМГ в его самые сложные первые дни. Решение совмещает в себе:
1. **Интерактивную панель управления (Iframe-виджет)** в интерфейсе Битрикс24, отображающую прогресс и обязательные задачи.
2. **Умного ИИ-ассистента** с RAG-поиском (Retrieval-Augmented Generation), способного отвечать на вопросы о внутренних регламентах КМГ как по текстовым документам, так и по отсканированным PDF-файлам (благодаря встроенному OCR).
3. **Систему риск-аналитики HR**, которая отслеживает дедлайны по задачам онбординга и анализирует психоэмоциональное состояние сотрудника на предмет выгорания или желания уволиться.

---

## ✨ Ключевые возможности (Features)

### 1. Автоматический старт онбординга
При первом входе (логине) сотрудника в Битрикс24 система автоматически перехватывает событие через Webhook, регистрирует пользователя в локальной БД PostgreSQL и нарезает **5 обязательных стартовых задач** в Битрикс24:
* 🛡️ Инструктаж по технике безопасности (ТБ)
* 💻 Инструктаж по информационной безопасности (ИБ)
* 🚪 Ознакомление с пропускным режимом
* 📜 Изучение Кодекса деловой этики КМГ
* ⚖️ Прохождение модуля Комплаенс

Бот отправляет сотруднику приветственное сообщение с приглашением запустить виджет.

### 2. Интерактивный виджет в Битрикс24 (Iframe)
Специальный встроенный дашборд позволяет сотруднику:
* 🎬 Посмотреть обязательное обращение Председателя Правления КМГ.
* 📈 Видеть текущий прогресс выполнения задач первого дня онбординга в реальном времени.
* ⏱️ Отслеживать дедлайны по ближайшим открытым задачам.
* 💬 В один клик перейти к общению со своим ИИ-наставником.

### 3. Умный RAG-поиск по регламентам КМГ
ИИ-помощник отвечает на вопросы по внутренним нормативным документам (ВНД) компании на двух языках (русский/казахский):
* **Векторная база знаний ChromaDB:** Все документы из папки `docs/` при запуске системы нарезаются на абзацы и векторизуются.
* **Гибридный OCR-движок (PyMuPDF + PyTesseract):** При загрузке документов система автоматически распознает тип страниц. Если это скан-копия (цифровой слой отсутствует), запускается OCR-модуль распознавания текста (поддерживающий русский и казахский языки `lang='rus+kaz'`), обеспечивая оцифровку документов «на лету».
* **Семантический фолбек:** Если запрос пользователя не покрывается базой ChromaDB, система использует интеллектуальный поиск по ключевым корням слов из базы `BACKUP_KNOWLEDGE` (график работы, дресс-код, соцпакет и медстрахование).
* **HR-эскалация:** Если ответ не найден, бот вежливо сообщает о перенаправлении вопроса HR-менеджеру.

### 4. Мониторинг выгорания и рисков увольнения
Интегрированный сервис `sentiment_service` анализирует сообщения сотрудника в реальном времени. При использовании триггерных слов (например, *«уволиться»*, *«устала»*, *«выгорел»*, *«надоело»*) система:
* Автоматически помечает сотрудника в БД флагом `at_risk = True`.
* Моментально отправляет **Push-уведомление HR-менеджеру** в Битрикс24 с текстом сообщения и ID сотрудника для превентивного вмешательства.

### 5. Уведомления и Крон-задачи (Scheduler)
В фоне работают фоновые планировщики:
* **Интервальный чекер (каждые 30 сек):** Проверяет статус выполнения задач в Битрикс24. Если до дедлайна (18:00 первого дня) осталось мало времени, а задачи не закрыты — отправляется алерт в колокольчик HR.
* **Итоговый крон в 16:00:** Проводит финальный аудит невыполненных задач. Направляет предупреждение сотруднику (в чат бота) с призывом завершить задачи и отправляет сводный отчет в HR-отдел.
* **Сброс флагов (00:00):** Ежедневно сбрасывает флаги активности для отправки новых карточек вовлечения (**Culture Fit**).

## 🛠️ Стек технологий

* **Backend:** FastAPI (Python 3.11), Uvicorn.
* **Database:** PostgreSQL 15, SQLAlchemy.
* **Vector DB:** ChromaDB (локальное хранилище во встроенном каталоге `/chroma_db`).
* **PDF & OCR:** PyMuPDF (`fitz`), Pillow, PyTesseract (Tesseract OCR).
* **Schedulers:** APScheduler.
* **Integration:** Bitrix24 REST API (JavaScript SDK для iframe-виджета).
* **Containerization:** Docker, Docker Compose.

## 🚀 Инструкция по развертыванию

### 1. Требования к системе
На хост-машине должны быть установлены:
* **Docker** и **Docker Compose**
* **Ngrok** (или любой другой инструмент для проброса портов наружу) для работы вебхуков Битрикс24.

### 2. Настройка переменных окружения
Создайте в корневой директории файл `.env` со следующим содержимым:

```ini
# Переменные для PostgreSQL
POSTGRES_USER=kmg_admin
POSTGRES_PASSWORD=kmg_secure_pass123
POSTGRES_DB=kmg_onboarding_db
POSTGRES_PORT=5432

# URL для SQLAlchemy (хост 'db' указывает на контейнер базы данных)
DATABASE_URL=postgresql://kmg_admin:kmg_secure_pass123@db:5432/kmg_onboarding_db

# Интеграция с Битрикс24 (замените на ваш вебхук и ID)
BITRIX_REST_URL=https://<ваш_домен>.bitrix24.kz/rest/1/<ваш_токен>/
HR_USER_ID=1

# Ключ OpenAI (опционально, для расширенного RAG)
OPENAI_API_KEY=sk-proj-...
```

### 3. Подготовка документов
Поместите регламентирующие документы компании в формате `.pdf` или `.txt` в директорию `docs/` в корне проекта. При первом запуске бэкенд автоматически проиндексирует их содержимое во встроенную ChromaDB.

### 4. Запуск контейнеров
Запустите сборку и старт сервисов одной командой:
```bash
docker-compose up -d --build
```
Это действие развернет:
1. Контейнер СУБД PostgreSQL с автоматической проверкой здоровья (healthcheck).
2. FastAPI бэкенд-сервис, который установит все системные зависимости (Tesseract OCR, Poppler) и автоматически выполнит миграции таблиц, загрузит 23 карточки Culture Fit и проиндексирует документы из папки `docs/`.

## 🔌 Настройка интеграции в Битрикс24

Для того чтобы приложение работало внутри портала Битрикс24, необходимо выполнить следующие шаги:

### Шаг 1: Проброс локального порта через Ngrok
Поскольку Битрикс24 требует HTTPS-ссылки для отправки вебхуков, пробросьте локальный порт `8000` наружу:
```bash
ngrok http 8000
```
Скопируйте сгенерированный адрес (например: `https://abcd-123.ngrok-free.dev`).

### Шаг 2: Регистрация Чат-бота
Перейдите по адресу вашего FastAPI сервиса для автоматической регистрации бота:
`https://<ваш_адрес_ngrok>/api/register-bot`

Это зарегистрирует чат-бота **Digital Buddy** в вашем портале Битрикс24 с привязкой событий:
* Обработка сообщений: `/bot/message`
* Приветствие нового пользователя: `/bot/welcome`

### Шаг 3: Настройка Iframe-приложения (Виджет)
В кабинете разработчика Битрикс24 создайте локальное приложение:
1. Выберите тип: **«Использовать только API»** или **«Слайдер/Всплывающее окно»**.
2. В качестве URL для первоначальной установки и URL для вкладки укажите:
   `https://<ваш_адрес_ngrok>/iframe`
3. Установите необходимые права доступа (Scope):
   * Пользователи (`user`)
   * Чат и роботы (`im`, `imbot`)
   * Задачи (`task`)
4. Сохраните изменения. Установите приложение на портал.

Теперь при открытии интерактивной панели у сотрудника будет отображаться его прогресс онбординга, кнопка перехода в чат с ИИ-помощником и ссылка на обращение руководства!

## 📈 Описание демонстрационного сценария (Скрипт презентации)
Для успешной демонстрации проекта экспертам или жюри можно использовать следующий сценарий:

1. **Регистрация пользователя:** Имитируйте вход нового сотрудника на портал. В этот момент бот **Digital Buddy** присылает приветствие, создает 5 задач с дедлайном 18:00 и дает ссылку на дашборд.
2. **Демонстрация Iframe-виджета:** Откройте виджет в меню Битрикс24. Покажите шкалу прогресса (0 из 5 выполненных задач) и ближайшую открытую задачу.
3. **Умный RAG-поиск:** Напишите в чат боту вопрос: *«во сколько обед?»* или *«какой дресс-код в пятницу?»*. Бот мгновенно выдаст точный регламентированный ответ со ссылкой на документ-источник.
4. **Демонстрация OCR (Сканы):** Задайте сложный вопрос по тексту, который содержится только в отсканированном PDF-файле внутри папки `docs/`. Бот задействует OCR, распознает текст и корректно ответит на него.
5. **Демонстрация риск-алерта (Выгорание):** Напишите боту фразу: *«я очень сильно устал, хочу уволиться»*. Бот ответит по регламенту, но в фоне в колокольчик HR-менеджеру (ID: 1) моментально прилетит критическое уведомление о риске выгорания сотрудника.
6. **Демонстрация просрочки задач:** Переведите время на сервере или дождитесь срабатывания крон-задачи, чтобы показать, как в 16:00 HR и сотрудник получают предупреждения о незакрытых чек-листах первого дня.
